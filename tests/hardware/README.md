# Hardware support matrix

No physical hardware is validated yet. No support claim may be inferred from the
package manifest. For each device record vendor/model, CPU/GPU, firmware mode,
Wi-Fi/Bluetooth/audio/storage controllers, ISO checksum, install/login results,
sleep/wake, external display, peripherals, update/reboot and recovery results.

QEMU BIOS is the first planned target, not evidence of physical device support.
